================================================================================
                         ALGORITHMS IMPLEMENTED
================================================================================

1. Prerequisite Validation (cli/prerequisite-validator.ts:66-194)
   - Algorithm: Recursive tree traversal
   - Complexity: O(n) where n = number of prerequisite nodes
   - Handles: AND, OR, COURSE, YEAR_STANDING, PERMISSION nodes
   - Features: Grade requirements, year standing checks

2. Schedule Generation (server/routes/schedules.ts:155-189)
   - Algorithm: Backtracking with forward checking
   - Complexity: O(b^d) where b = sections/course, d = courses
   - Optimization: Conflict pruning, early termination
   - Guarantees: Finds all valid conflict-free schedules

3. Time Conflict Detection (server/routes/schedules.ts:87-106)
   - Algorithm: Interval overlap check
   - Complexity: O(1) per pair of time slots
   - Formula: start1 < end2 AND start2 < end1

4. Audit Parsing (cli/audit-parser.ts:16-52)
   - Algorithm: Regex pattern matching
   - Complexity: O(n) where n = file size
   - Extracts: Student info, completed courses, grades

================================================================================
                         TROUBLESHOOTING
================================================================================

Backend won't start?
  → Check PostgreSQL is running
  → Run: pnpm run db:setup
  → Check .env file has DATABASE_URL

Frontend can't connect?
  → Check backend is running on port 3001
  → Check CORS is configured (already done)
  → Check API_BASE_URL in frontend config

Database errors?
  → Run: pnpm run db:reset (⚠️ deletes data)
  → Run: pnpm run db:seed
  → Check: npx prisma studio

Type errors?
  → Run: pnpm run server:build
  → Check imports are correct
  → Ensure @types packages installed
